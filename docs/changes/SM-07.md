# SM-07 SCM 菜单动作宿主

日期：2026-09-05。父提交：`3833cb958647411f0b4bb0ae489ab406b213e8ae`。

## 变更与边界

在现有 bridge v3 上增加 menuApiVersion 1 与 owner 动作注册，不建立新的会话业务状态。动作只接收宿主刚确认的 nativeSessionId/workspaceId，注册者不能提供 logicalSessionId。保留官方菜单、置顶、工作区归档和 Maintenance 删除回执后隐藏。

owner 替换与注销支持安全 disposer；可见/可用判定异常仅影响单项。宿主 ready/unavailable 通知支持加载顺序变化与重载；卸载、替换中止动作 signal，迟到结果不显示反馈。加入键盘打开、焦点移动和 Escape，延迟选中被关闭后不再生成菜单。接入协议见 [menu-action-host.md](../menu-action-host.md)。

此次仅交付 SCM 宿主，Maintenance 消费端仍待 SM-03/06 后实施。当前安装包没有因同名版本自动获得功能；版本保持 0.3.1，最终版本由协调者分配。
